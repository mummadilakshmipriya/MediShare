# Java Servlet + JSP + JDBC (Oracle) sample

This is a separate Java web module demonstrating the reference technologies. It is not used by the React frontend, which calls the Node/Express API.

## Database table
Run in Oracle:
```sql
CREATE TABLE MEDICINE_LISTING (
  ID NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  MEDICINE_NAME VARCHAR2(100) NOT NULL,
  QUANTITY NUMBER NOT NULL,
  EXPIRY_DATE DATE NOT NULL,
  DONOR_NAME VARCHAR2(100) NOT NULL
);
```

## Configure
Set environment variables `ORACLE_URL`, `ORACLE_USER`, and `ORACLE_PASSWORD`.
Example URL format: `jdbc:oracle:thin:@//localhost:1521/FREEPDB1` (adjust for your installation).

Oracle JDBC drivers may require a version/license/distribution choice matching your database. Add the correct driver dependency in `pom.xml` or place the institution-approved driver where Maven/Tomcat can access it.

Build using `mvn package`, then deploy the WAR to Apache Tomcat 10.1+.
Open `/medishare-java/medicines`.

This is a classroom sample. Add authentication, authorization, CSRF protection, validation, and secure configuration before any real deployment.
